🏚️ Casa Infestata

Progetto Computer Graphics A.A.2023/24 - Applicazione 3D Interattiva

📋 Descrizione dell'Applicazione

Casa Infestata è un'esperienza 3D immersiva che trasporta l'utente in un ambiente horror interattivo. L'applicazione combina elementi di esplorazione in prima persona con un sistema di illuminazione dinamica e interazioni ambientali.

Concept Principale: Il giocatore si trova in una stanza buia e deve trovare l'interruttore della luce per illuminare l'ambiente, scoprendo gradualmente gli oggetti inquietanti che popolano lo spazio.

🎯 Obiettivi del Progetto

  • Creare un'esperienza 3D coinvolgente e atmosferica
  • Implementare un sistema di illuminazione realistico
  • Fornire controlli intuitivi per desktop e mobile
  • Dimostrare competenze avanzate in WebGL e computer graphics

🖥️ Shaders GLSL

// Vertex Shader - Trasformazioni geometriche attribute vec4 a_position; attribute vec3 a_normal; attribute vec2 a_texcoord; uniform mat4 u_model; uniform mat4 u_view; uniform mat4 u_projection; uniform mat4 u_lightSpaceMatrix; varying vec3 v_position; varying vec3 v_normal; varying vec2 v_texcoord; varying vec4 v_fragPosLightSpace; void main() { vec4 worldPosition = u_model * a_position; v_position = worldPosition.xyz; v_normal = mat3(u_normalMatrix) * a_normal; v_texcoord = a_texcoord; v_fragPosLightSpace = u_lightSpaceMatrix * worldPosition; gl_Position = u_projection * u_view * worldPosition; }

💡 Sistema di Illuminazione

  • Phong Lighting Model: Componenti ambient, diffuse e specular
  • Shadow Mapping: Ombre dinamiche in tempo reale
  • PCF (Percentage Closer Filtering): Ombre soft e realistiche
  • Multi-light System: Luce interna (lampadario) + luce esterna (finestre)
  • Attenuation: Attenuazione realistica della luce con la distanza

🌑 Shadow Mapping Algorithm

// Shadow Mapping con PCF float calculateShadow(vec4 fragPosLightSpace) { vec3 projCoords = fragPosLightSpace.xyz / fragPosLightSpace.w; projCoords = projCoords * 0.5 + 0.5; float shadow = 0.0; vec2 texelSize = vec2(1.0) / vec2(1024.0); // PCF (Percentage Closer Filtering) for(int x = -1; x <= 1; ++x) { for(int y = -1; y <= 1; ++y) { float pcfDepth = texture2D(u_shadowMap, projCoords.xy + vec2(x, y) * texelSize).r; shadow += currentDepth - bias > pcfDepth ? 1.0 : 0.0; } } return shadow / 9.0; }
